# なんでもノート（GitHub Pages用）

## 内容
- スマホ対応のハンバーガーメニュー
- 記事検索（キーワード）
- タグによる記事の絞り込み
- おすすめ記事、プロフィール欄
- 記事ページ一式
- スマホ向けAdMax広告枠（PCでは非表示のCSS設定）

## 公開方法
1. ZIPを展開します。
2. ファイル一式をGitHubリポジトリのルートにアップロードします。
3. GitHubの Settings → Pages で公開設定を確認します。

## 広告について
AdMaxのスクリプトはトップページおよび記事ページに配置されています。広告サービス側の仕様により、実際の表示サイズや表示可否は変わることがあります。上下に同じ広告タグを複数置く運用が許可されているか、AdMaxの規約・管理画面で確認してください。

## 記事を追加するには
既存のHTMLファイルを参考に新しいHTMLファイルを作成し、`index.html` の記事一覧にもリンクを追加してください。GitHub Pagesは静的サイトなので、記事の追加はリポジトリへのファイル追加・更新で行います。
