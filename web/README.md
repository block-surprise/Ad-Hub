# なんでも。— GitHub Pages 用サイト

## 公開方法
1. GitHubでリポジトリを開きます。
2. このZIP内のファイルをリポジトリ直下にアップロードして、既存ファイルを置き換えます。
3. `Settings` → `Pages` で公開設定を確認します。

## 記事を増やす
HTMLファイルをコピーして、タイトル・本文を編集し、トップページ `index.html` の記事一覧にリンクを追加してください。

## 広告について
AdMaxの広告コードを各ページに入れています。CSSではスマートフォン幅（700px以下）のみ表示し、320px幅の広告を中央に置く設定です。PCでは非表示です。広告配信側のスクリプトが表示サイズを決めるため、実際の見え方はAdMax側の仕様にも左右されます。

## 注意
GitHub Pagesは静的サイトです。記事を追加・編集するには、GitHub上でHTMLファイルを変更して公開します。ZIPに含まれない古いファイルは、リポジトリ内に残っていると公開されたままです。不要なページはGitHub側で削除してください。
