# なんでも。 — GitHub Pages

## ファイル
- `index.html`: トップページ・記事一覧
- `information-literacy.html`: 情報リテラシーとは
- `why-write.html`: なぜ人は文章を書くのか
- `internet-memory.html`: 昔のインターネットの空気が好き
- `small-happiness.html`: 小さな楽しみを集めてみる
- `question-everyday.html`: 当たり前って、本当に当たり前？
- `about.html`: このサイトについて
- `style.css`: 共通デザイン

## 公開手順
1. ZIPを解凍して、ファイルをGitHubリポジトリのルートにアップロード。
2. GitHubリポジトリの Settings → Pages を開く。
3. Source を `Deploy from a branch`、Branch を `main`、フォルダを `/(root)` にして Save。

## 広告について
ご指定のAdMaxスクリプトを、トップページと各記事ページのサイドバーに入れています。広告配信はAdMax側の設定、審査、ブラウザの制限などによって表示が変わることがあります。公開前に、ご自身のサイトでの利用条件やプライバシー表示などを確認してください。

## 新しい記事の追加
既存のHTML記事ページを複製して本文・タイトル・カテゴリーを書き換え、`index.html` に記事カードを追加してください。CSSは全ページで共通です。
