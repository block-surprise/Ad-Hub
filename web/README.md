# なんでもノート（GitHub Pages）

## 公開方法
1. ZIPを展開します。
2. ファイル一式をGitHubリポジトリのルートにアップロードします。
3. GitHubの Settings → Pages で公開設定を行います（Branch: main / root など）。

## 広告について
- 指定されたAdMaxスクリプトを、ページ上部と下部の独立した広告エリアに設置しています。
- 画面幅700px以下（スマートフォン想定）でのみ広告エリアを表示し、PC幅では非表示にします。
- 広告自体の実際の表示サイズ・レスポンシブ動作は配信元スクリプト側にも依存します。320×100のスマホ向け広告ユニットが管理画面で選ばれていることを確認してください。
- 上下に同じ広告スクリプトを配置すると、配信サービス側の仕様によっては片方しか表示されない可能性があります。もしそうなる場合は、管理画面で複数設置が許可されているか確認してください。

## 記事を増やす
既存のHTMLファイルを参考に新しいHTMLを作り、index.htmlの記事一覧にリンクを追加してください。
