# なんでも。
GitHub Pages向けのシンプルな個人記事サイトです。

## ファイル
- `index.html`: トップ・記事一覧
- `information-literacy.html`: 情報リテラシーとは
- `why-write.html`: なぜ人は文章を書くのか
- `internet-memory.html`: 昔のインターネットの空気が好き
- `small-happiness.html`: 小さな楽しみを集めてみる
- `question-everyday.html`: 当たり前って、本当に当たり前？
- `about.html`: このサイトについて
- `style.css`: 共通デザイン

## 公開
GitHubのリポジトリのルートにファイルをアップロードし、Settings → Pages → Deploy from a branch → `main` / `/(root)` を選んで保存してください。

## 広告
指定されたAdMaxスクリプトをトップページと記事ページのサイドバーに入れています。広告スクリプトが外部の要素を生成するため、表示サイズなどは広告側の配信仕様に従います。今回のCSSでは広告枠の外にはみ出しにくいようにしていますが、広告配信側が独自の固定サイズやスタイルを指定する場合、完全には制御できません。
